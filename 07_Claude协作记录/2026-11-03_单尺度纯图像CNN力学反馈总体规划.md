# 单尺度纯图像CNN力学反馈总体规划

日期：2026年11月3日。

目标是训练一个只读取组织图的力学预测器，再冻结预测器，将生成图的力学预测误差反向传播给扩散模型。成分继续作为扩散模型的条件，不作为这版力学CNN的输入。本稿是总体设计，未实现或启动新CNN训练，也不是C0/C1开训许可。

## 本项目第一版候选结构

```text
原生RGB 256×256
  → Conv(3→16)+BN+ReLU+MaxPool2
  → Conv(16→32)+BN+ReLU+MaxPool2
  → Conv(32→64)+BN+ReLU
  → GlobalAveragePool，64维
  → Linear(64→20)+ReLU+Dropout0.3
  → Linear(20→12)+ReLU+Dropout0.3
  → Linear(12→2)
  → 标准化后的峰值应力、应变预测
```

256像素窗口用于匹配已有扩散生成分辨率，不把200像素图拉伸到256。三个卷积先拟定3×3、stride1、padding1；这些是本项目的实现选择，不能写成已核实的论文参数。采用该实现时模型约2.5万参数。GAP减少参数，但不保证保留完整空间排列；这是一版小型单尺度候选，不添加多分支、DCN或注意力。

CNN在真实组织窗口上端到端训练。进入扩散反馈后才冻结整个CNN；不要求先通过手工硬描述符代理，也不要求只做硬描述符蒸馏。M0-v2阴性结论保留，新版本登记为看过前两轮结果后的第三轮开发。

两个输出分别对应项目现有`peak_stress_MPa`和`endpoint_strain_pct`。应变按用户决定作为暂定断裂应变目标，但原始数据字段和报告仍注明它来自DIC终点，尚无已确认断裂的逐试次证据。各训练折分别计算目标均值和标准差；在标准化尺度上等权，避免MPa数值压过应变。

## 阶段一 数据与训练

1. 沿用21个开发合金及其真实图像、合金中位标签；ID03隔离。不得删除ID21或改变现有标签以获得好结果。
2. 先按合金划分，再裁切与增强。相邻、重叠或增强后的窗口始终跟随母合金，不跨越训练和评价边界。
3. 优先复用现有窗口坐标，保留原生像素与边界线宽；新增在线裁切位置、次数、随机种子需要预登记。评价窗口固定，不按模型分数挑窗口。
4. 第一版不默认使用色相、饱和度、侵蚀、膨胀、遮挡或强模糊。IPF颜色有取向含义，不能直接套用自然照片的颜色增强。旋转和翻转还需核对坐标、拉伸方向及IPF参考方向；未核实前采用随机裁切，几何增强作为预登记的第二版本，不能在看到外层结果后任意添加。
5. 合金均衡采样，一个批次包含多个合金，避免BatchNorm只看到同一合金的重复窗口。建议每组K=4个同合金窗口，逐窗通过同一CNN，再将两个预测分别取均值，与该合金标签计算损失。均值监督是本项目相对论文逐窗标签广播的适配，尚未证明更好。记录逐窗预测离散度，不能只看均值。
6. 组级损失为两个标准化目标MSE的均值。以Adam、学习率1e-3、最多200轮、余弦退火为固定起点，不开展大范围搜索。每轮定义固定的合金组采样预算，比较时对齐更新次数。

真实窗口重叠、生成组来自独立噪声，两侧聚合方差不同。K=4是待检验的起点，不代表4个独立真实试样；训练和生成读出的组方差检查通过后，才能固定反馈用K。

## 阶段二 纯图像预测器验收

外层留一合金，共21折。外层每折20个合金内部再做固定4折分组验证，用于选择训练轮数；把内层最佳轮数按预登记规则汇总后，在全部20个外层训练合金上重新训练，再预测被留出的1个合金。目标标准化、任何拟合预处理和早停都只使用对应训练部分。

先固定3个种子，完整报告各种子和集成结果，不挑最好种子。21折的折外预测合并后计算RMSE、MAE、R²、秩相关与逐合金误差；单折只有1个合金，不计算单折R²。窗口和种子均不增加独立合金数。

比较模型至少包括训练折均值预测器、仅成分岭回归和纯图像CNN。成分模型只作诊断对照，不进入CNN输入。“比仅成分提升15%”不再被当作这一纯图像任务唯一的必要门；这属于新的评价问题，不能据此回改旧M0-v2未通过的判定。

正式执行前另写可运行预注册，固定纯图像目标的绝对误差容忍度、相对训练均值基线的最低收益、跨种子稳定规则及负对照。总体规划不把任意R²阈值当物理定律，也不在看到新CNN结果后放宽门。标签置换若开展，必须明确是否重训完整CNN流程；只置换冻结特征回归头不能冒充完整流程检验。

预测准确只是第一部分。还要检查颜色或标识捷径、合理结构敏感性、窗口稳定性；Grad-CAM作辅助，不能仅凭热图宣称物理机制。结构扰动没有新力学真值，不能武断规定每一种扰动都必须令强度单调变化。

峰值应力和应变分别判读；某一目标不可靠时，不把它硬接入反馈。由于21合金已被多轮开发使用，本轮仍是探索性开发，需要新合金/新试样作最终确认。

## 阶段三 生成域与梯度检查

通过真实图预测验收后，再冻结CNN，分别读出真实图、VAE重建图、训练噪声下的单步x0估计图和S0自由生成图。评价它们的特征支持范围、硬形貌、预测稳定性及模型间分歧；对生成图没有新实测力学标签，不能声称算出了生成图真实预测误差或真实力学性能。

禁止将明显失真的生成图自动赋予母合金标签，作为大量新增实测训练样本。生成图扩增预测器属于另一个有弱标签假设的研究，不在首版默认启用。

零更新探针检查CNN对输入图像及U-Net的梯度、两个目标梯度范数与余弦、力学项相对扩散MSE的量级。CNN切换eval以固定BatchNorm和关闭Dropout，但不能在no_grad里执行反馈前向；VAE同样冻结参数、保留解码的输入梯度。解码和CNN反传优先FP32。

同时回收既有轨迹复现诊断，确定单步x0可靠范围与布局缺陷形成阶段是否相交。新CNN不会自动消除噪声时段覆盖不足或自由生成域偏移。过不了相应门时保留预测分析，不直接开C1。

## 阶段四 扩散反馈对照

```text
成分+噪声
  → U-Net的干净潜变量估计
  → 冻结VAE解码
  → 冻结纯图像CNN
  → K张图的预测均值
  → 与训练合金实测峰值应力和应变比较
  → 梯度穿过CNN和VAE
  → 更新约定的U-Net模块与条件编码器
```

总损失为原扩散MSE加总系数乘力学损失。两目标标准化后等权；总系数通过固定零更新批次标定后锁定，不按ID03或反馈结果搜索。代理的真实图残差不能被当成一定可消除的物理误差，反馈损失下降也不能独自作为成功证据。

具体更新范围拟定为整个U-Net与成分条件编码器；VAE和已验收CNN冻结参数但保留输入梯度。CNN拟合真实标签用MSE，扩散反馈阶段先沿用现有标准化Huber。分块梯度、时间范围、单步估计与自由生成的差异及待Claude裁决事项见同目录`2026-11-03_纯图像CNN反馈梯度链路与更新范围_请Claude复核.md`。这些是待复核的实现选择，尚未接入新CNN代码。

S0是哈希核对后的约定纯MSE起点。C0从S0作普通MSE续训，C1从同一S0作MSE加力学项续训；两臂同预算、优化器、种子、组采样和更新模块。首轮不同时叠加Dice或结构统计损失。

主比较为C1对C0，并报告相对S0的变化。成功证据需要独立硬组织指标、合金特异性、复制与多样性检查共同支持，不能只看同一个反馈CNN评分。ID03只在开发决定锁定后作为探索性留出报告。

## 执行顺序和交付

先完成单尺度CNN模型、分组合金窗口采样和独立训练入口；验证数据隔离、目标标准化与梯度链路的软件测试。再冻结训练协议和判据，运行真实图预测验收。只有通过后才拟合最终冻结预测器、做生成域与零更新探针；最后才考虑C0/C1。

预期交付包括网络和配置、划分与窗口清单、逐合金折外预测、种子完整结果、模型权重与归一化、诊断与停止/继续报告。当前原图和两个力学表已经存在，通常不需补充新类别的数据；若要忠实复现论文未写清的实现细节，应回收原单尺度CNN代码。
