## 假设、控制变量与原理

问题：在同一起点和相同微调预算下，只改变时间步损失权重，能否改善**从纯噪声自由生成**的组织形态？

| 项目 | A_mse | B_minsnr5 |
|---|---|---|
| 初始 U-Net | A raw50k | 完全相同 |
| 初始成分编码器 | 同检查点 `model_1.safetensors` | 完全相同 |
| 噪声预测 | epsilon | epsilon |
| 损失 | 原始普通 epsilon MSE | 每样本 epsilon MSE × Min-SNR 权重 |
| gamma | 关闭/null | 5 |
| 额外优化步数 | 5000 | 5000 |
| 优化器 / 学习率计划 | 全新 AdamW；峰值 1e-5；100 步 warmup + cosine | 完全相同 |
| 训练随机种子 | 20260721 | 完全相同 |
| 其他训练设置 | 从 A 的实际 TensorBoard hparams 恢复 | 完全相同 |

两组配置除 `snr_gamma` 和输出目录外必须相同，否则拒绝运行。5000 步、1e-5 和 100 步 warmup 是本轮**保守 pilot 默认值**，不是已验证的最优超参数。

历史 50k 已到 cosine 计划终点。这里不加载旧优化器、旧学习率状态、旧随机状态或旧 EMA；两组共同以 raw50k 的模型权重重新开始微调。`global_step=5000` 表示额外 5000 步，`effective_total_step=55000` 标明来源总步数，避免把历史 50000 误当成本轮已完成、导致实际 0 步训练。

**单变量只指 A 与 B 之间。** 两组相对历史 raw50k 都有新的优化历程，所以不能把 B 与历史起点的差异全部归因于 Min-SNR，必须先比较新 A 与新 B。

对 epsilon 预测，令 `SNR(t)=alpha_bar(t)/(1-alpha_bar(t))`：

```text
L_A = mean_i MSE(epsilon_pred_i, epsilon_i)
w(t) = min(SNR(t), 5) / SNR(t)
L_B = mean_i [w(t_i) * MSE(epsilon_pred_i, epsilon_i)]
```

实现按样本先平均空间/通道误差，再加权；代数与累计计算使用 float32，并处理零 SNR 极限。关闭时仍调用原来的 `F.mse_loss(prediction.float(), target.float())`。此实现不把 epsilon 的权重公式静默套给 v-prediction。

这会降低高 SNR（低噪声）任务的相对权重，重新分配时间步之间的训练贡献；**不是直接增加晶界监督、不是奖励某个连通区域数量，也不保证解决布局问题**。013 同时改变了多项设置，其结果只能提供线索，不能证明 Min-SNR 是 017 的病因或解法。“epsilon MSE 奖励 20 个大晶粒”的旧说法不再使用。

## 判读与停止

主要比较固定末步 5000 的 B 对 A；raw50k 只是共同起点参考，不根据中途哪张图漂亮挑“最佳 checkpoint”。

视觉检查和多种子描述符共同判断：05/07 的大块、渐变和分隔不足是否改善，20 是否更接近自己的真实组织而非变成另一种碎点，黑线比例、面积分布、颜色及空间统计是否同时合理。区域数增加但只是黑线增粗/碎点增多，不算改善；B 的加权训练 loss 更低也不算质量证据。

本轮只有一个训练种子、一折、有限评价图，**不能预先认定 Min-SNR 有效**。有一致、可见且定量支持的改善再交用户/Claude 审阅；没有清楚改善就报告 pilot 阴性或证据不足，不自动扩大步数、提高 gamma 或叠加新 loss。短微调阴性也不能单独证明从头训练的 Min-SNR 无效。
