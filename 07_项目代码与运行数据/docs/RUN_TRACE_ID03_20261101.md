将fold03_trace_id03_20261101.tar.gz上传到/root/autodl-tmp，进入既有Python环境和项目根目录后解压。需要matplotlib绘制曲线，缺少时安装。

入口为`python -u -m scripts.diagnose_structure_trajectory`。必需参数`--output`必须是不存在的新目录。默认`--experiment`是原14_Fold03_MSE_结构统计_5k_运行；若服务器用其他实验目录，显式传入。

- `--mode all`：两项一次执行；分别运行便于独立检查和保留失败输出。

输出包括采样输入哈希、源码/模型哈希、PNG、逐时段CSV、拼图和曲线。高噪声x0附解码越界比例，早期图只作暂定估计。N和最大区域均是RGB分割代理；不能据单个高噪声快照认定形貌根因。
